# Product

What the site does. Pages and features:

- Homepage
  - Avatar photo
  - Skill highlights
- Résumé
  - HTML version
  - PDF version
  - JSON Resume version
  - Single source of truth
    - CSS for differences
- Skills
  - Card list page with filters
    - Name
    - Icon
    - Years used
    - Versions used (freeform)
    - 5-star rating (half stars allowed)
    - Tags
    - Notes
- Projects
- Blog
- Contact page
  - Obfuscated email address
  - Contact form
    - Stored in database
    - Email sent to me
- Secret admin page
  - Sign in with a passkey: Red, Purple, or a phone (no password)
  - Passkey page (`/admin/passkeys`): list, add a phone or a security key, rename, and remove, each change confirmed with a passkey already registered
  - Contact form submission list page
  - Editors for JSON Resume
