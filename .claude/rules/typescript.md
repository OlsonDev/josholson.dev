# TypeScript

`mise web:lint` runs the format check (`bun fmt`) and `bun lint`. The rules are in `web/bunfig.toml`, and `bun lint` reads them for `.svelte` files only because `web/.oxlintrc.json` exists (empty on purpose; delete it when `bun lint` lints Svelte without it, [oven-sh/bun#45163](https://github.com/oven-sh/bun/issues/45163)).

- `Date` is banned, as a value, as a type, and through `globalThis` or `window`: use Temporal (`Temporal.Instant` for an instant). Like `BannedSymbols.txt` for C#, the message says what to use instead, and a new ban goes in `web/bunfig.toml`.
- Await every promise, or return it. `typescript/no-floating-promises` and `no-misused-promises` enforce it, but they need types, so they do not run on `.svelte` files: keep API calls in `.ts` modules and `load` functions.
- `for...of`, not `Array#forEach` (like C#'s `foreach`), and `===`.
- Only the `<script>` of a `.svelte` file is linted. Markup is not.
- Never edit `src/lib/api/schema.ts` (generated by `mise api:openapi`); it is excluded from linting.
- A disable comment names the rule and says why (`// eslint-disable-next-line <rule> -- <reason>`), and `bun lint` reads ESLint's syntax.
- Bun has no `bunx` here: write `bun x`.
